Special Codes

Escape Characters: \n and \t ⚡

Escape characters add special formatting inside text:

\n
New Line Character
\t
Tab Space Character
Code Example:
print("Hello\nWorld")
Terminal Output:
Hello World
💡 \n starts a new line, while \t adds horizontal tab space!
